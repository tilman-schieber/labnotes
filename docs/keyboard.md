# Keyboard

Everything in the editor is reachable without the mouse. `/shortcuts` inside the editor shows this list.

## Writing

| Keys | Does |
| --- | --- |
| `#name` | reference an entity or document; ↑/↓ move, Tab/Enter accept, Escape keeps plain text; an unknown name becomes a draft |
| `@name` | reference a person |
| `/` | command palette |
| `25 mg` + Space | quantity token |
| number + Space, then Tab | pick the suggested unit |
| Enter on a selected quantity token | edit it (select tokens with the arrow keys) |
| Ctrl/Cmd + Shift + T | insert the current time |
| Ctrl/Cmd + . | link the next underlined name or amount after the caret |
| Ctrl/Cmd + Shift + L | link every underlined name and amount |
| `## ` … / `- ` / `[ ] ` at line start | heading / bullet / task list |
| `**bold**`, `*italic*` | marks while typing |
| Ctrl/Cmd + B, I | bold, italic |
| Ctrl/Cmd + Z, Shift + Z | undo, redo |
| Backspace after a conversion | undo the input rule (token back to text) |

## Reaction tables

Rows are ordinary inputs: Tab moves between cells, Enter commits an amount, the role is a select, "lim." is a radio button.

## Registry

Forms are standard: Enter submits label/alias inputs; pickers list candidates as you type.

## Escape hatches

Escape closes any popup (reference picker, unit list, dialogs) and leaves your text as it is.
